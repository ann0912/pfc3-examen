# Diseño frontend para PFC III

- Define el rol, su tarea principal y la información necesaria para completarla.
- Usa navegación, etiquetas y acciones específicas del caso. Haz visible la
  acción principal y elimina secciones de relleno.
- Reutiliza componentes y mantén una jerarquía consistente de tipografía, color
  y espaciado. Selecciona imágenes si ayudan a reconocer o entender el contenido.
- Revisa carga, vacío, error y confirmación. Comprueba el recorrido en escritorio
  y móvil, la navegación con teclado y la legibilidad. Registra qué verificaste.
